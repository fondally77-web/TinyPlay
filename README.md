# 🎮 TinyPlay - 動物をクリックしよう！

幼稚園児でも楽しめる、カラフルで楽しいクリックゲームです！

## 🌟 ゲームの特徴

- 🎨 **カラフルなデザイン**: 明るく楽しい色使いで子供たちの興味を引きます
- 🐶 **かわいい動物たち**: 12種類の動物の絵文字が登場！
- 🎯 **簡単な操作**: クリックするだけの簡単な操作
- ⏱️ **30秒チャレンジ**: 短い時間で飽きずに楽しめます
- 🔊 **効果音**: クリックするたびに楽しい音が鳴ります
- 📱 **レスポンシブデザイン**: スマホでもタブレットでもパソコンでも遊べます

## 🎯 遊び方

1. **スタートボタンを押す**: 「スタート！」ボタンをクリック
2. **動物をクリック**: 画面に現れる動物をすばやくクリック
3. **ポイントゲット**: 動物をクリックするたびに10ポイント！
4. **時間内にたくさんクリック**: 30秒以内にできるだけ多くの動物をクリックしよう

## 🚀 始め方

### 方法1: ブラウザで直接開く

1. `index.html` をダブルクリックしてブラウザで開く
2. すぐに遊べます！

### 方法2: ローカルサーバーで起動

```bash
# Pythonを使う場合
python -m http.server 8000

# Node.jsのhttp-serverを使う場合
npx http-server
```

その後、ブラウザで `http://localhost:8000` を開いてください。

## 🌈 カスタマイズ

`js/game.js` の `GAME_CONFIG` オブジェクトを編集することで、ゲームの設定を変更できます:

```javascript
const GAME_CONFIG = {
    animals: ['🐶', '🐱', '🐰', ...],  // 動物の種類
    gridSize: 9,                        // グリッドサイズ（3x3）
    gameDuration: 30,                   // ゲーム時間（秒）
    spawnInterval: 800,                 // 動物が現れる間隔（ミリ秒）
    pointsPerClick: 10                  // クリックごとの得点
};
```
