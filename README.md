# 🎮 TinyPlay - 動物をクリックしよう！

幼稚園児が親子で会話を楽しみながら遊べる、カラフルで楽しいクリックゲームです！

## 🌟 ゲームの特徴

- 🎨 **カラフルなデザイン**: 明るく楽しい色使いで子供たちの興味を引きます
- 🐶 **かわいい動物たち**: 12種類の動物の絵文字が登場！
- 👨‍👩‍👧 **会話を楽しめる**: ゆっくりしたペースで、親子で「この動物はなあに？」「どんな鳴き声かな？」と会話できます
- 🎯 **簡単な操作**: クリックするだけの簡単な操作
- 🔢 **複数の動物が出現**: 2〜3匹の動物が同時に出現するので、探す楽しさがあります
- ⏱️ **60秒でゆったり**: ゆっくり1分間、会話を楽しみながら遊べます
- 🔊 **効果音**: クリックするたびに楽しい音が鳴ります
- 📱 **どのデバイスでも3×3**: スマホでもタブレットでもパソコンでも3×3の見やすいグリッド

## 🎯 遊び方

1. **スタートボタンを押す**: 「スタート！」ボタンをクリック
2. **動物を探そう**: 画面に2〜3匹の動物が現れます
3. **会話を楽しもう**: 「この動物はなあに？」「どんな鳴き声するかな？」と親子で会話
4. **動物をクリック**: お気に入りの動物をクリックしてポイントゲット（10ポイント）
5. **ゆっくり楽しもう**: 60秒間、ゆったりしたペースで楽しめます

## 🚀 始め方

### 方法1: ブラウザで直接開く

1. `index.html` をダブルクリックしてブラウザで開く
2. すぐに遊べます！

### 方法2: ローカルサーバーで起動

```bash
# Pythonを使う場合
python -m http.server 8000

# Node.jsのhttp-serverを使う場合
npx http-server
```

その後、ブラウザで `http://localhost:8000` を開いてください。

## 🌈 カスタマイズ

`js/game.js` の `GAME_CONFIG` オブジェクトを編集することで、ゲームの設定を変更できます:

```javascript
const GAME_CONFIG = {
    animals: ['🐶', '🐱', '🐰', ...],  // 動物の種類
    gridSize: 9,                        // グリッドサイズ（常に3x3）
    gameDuration: 60,                   // ゲーム時間（秒）
    spawnInterval: 2500,                // 動物が現れる間隔（ミリ秒）
    pointsPerClick: 10,                 // クリックごとの得点
    maxActiveAnimals: 3,                // 同時に表示する動物の最大数
    minActiveAnimals: 2                 // 同時に表示する動物の最小数
};
```
